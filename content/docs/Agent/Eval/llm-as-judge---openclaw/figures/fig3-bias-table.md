# 图3：偏差类型汇总与缓解策略

| 偏差类型 | 现象 | 影响 | 缓解策略 |
|----------|------|------|----------|
| **位置偏差**<br>Position Bias | 倾向于选择排在前面或第一个呈现的答案 | 导致评估不公平，位置交换后结果反转 | • 随机化呈现顺序<br>• 交叉评估（AB/BA各评一次取共识）<br>• 盲评（不标注模型身份） |
| **自偏好偏差**<br>Self-Preference | Judge 模型偏好与自身生成风格/知识分布相似的输出 | 同模型评估时分数虚高，跨模型比较失真 | • 跨模型交叉评估（GPT-4 评 Claude，Claude 评 GPT-4）<br>• 多模型投票聚合<br>• 对 Judge 进行去偏微调 |
| **长度偏差**<br>Verbosity Bias | 偏好更长、更详细的回答，即使内容质量无实质提升 | 鼓励模型"灌水"，偏离用户需求 | • 长度归一化预处理<br>• Rubric 中明确"简洁性"维度<br>• 长度惩罚因子 |
| **格式偏差**<br>Format Bias | 偏好特定格式（如表格、列表）的输出 | 格式偏好压倒内容质量 | • 去除格式后评估内容<br>• 多维度独立打分<br>• 格式作为独立评分维度 |
| **知识幻觉**<br>Knowledge Hallucination | Judge 自身知识不足导致误判正确答案 | 错误否定、事实判断错误 | • 接入外部知识源（搜索、知识库）<br>• 事实核查插件<br>• 领域专家样本校准 |
| **一致性偏差**<br>Inconsistency | 同一输入多次评估产生不同结果 | 评估不可复现，缺乏可信度 | • temperature=0<br>• 多次采样取投票共识<br>• 固定随机种子 |
| **文化/语言偏差**<br>Cultural Bias | 对特定语言/文化背景的回答有偏好 | 多语言场景下不公平 | • 多语言 Judge 模型<br>• 语言无关 Rubric<br>• 分语言独立评估 |
